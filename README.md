# Tic Tac Toe Pro 🎮
Hi, this is my Tic Tac Toe project. I created this game using HTML, CSS and JavaScript.
In this game, you can play with another player or play against the computer. I also added different difficulty levels to make the game more interesting.

## Screenshot
![Tic Tac Toe Game](screenshots/gameplay.png)

## Features
- Play with 2 players.
- Play against the computer.
- Three difficulty levels: Easy, Medium and Impossible.
- Scoreboard to track wins and draws.
- New Round option.
- Reset Scores option.
- Responsive design for different screen sizes.

## Technologies Used
- HTML
- CSS
- JavaScript

## Difficulty Levels
- **Easy:** Computer makes random moves.
- **Medium:** Computer tries to make better moves and sometimes plays randomly.
- **Impossible:** Computer uses the Minimax algorithm to choose the best move.

## How to Run This Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start playing the game.
